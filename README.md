# Proyek AI & Data Science Dicoding

Kumpulan portofolio dan proyek submission pembelajaran **Artificial Intelligence & Data Science** Dicoding Indonesia.

---

## 🌟 Proyek Unggulan: Analisis Sentimen Ulasan Shopee Indonesia

Analisis sentimen ulasan pengguna aplikasi **Shopee Indonesia** di Google Play Store (58.300+ data ulasan) menggunakan Machine Learning (TF-IDF + Logistic Regression) dan Deep Learning (LSTM, Bi-GRU, DNN).

### 🎬 Demo Aplikasi Streamlit
Tersedia aplikasi web demo interaktif berbasis Streamlit:

![Demo Aplikasi Streamlit](Proyek%20Sentiment%20Analisis/demo.gif)

> 🎥 **Video Demo:** [Tonton Video Demo (MP4)](Proyek%20Sentiment%20Analisis/demo.mp4) | [Format WebM](Proyek%20Sentiment%20Analisis/demo.webm)

### 🚀 Cara Menjalankan Demo:
```bash
cd "Proyek Sentiment Analisis"
pip install -r requirements.txt
streamlit run app.py
```
